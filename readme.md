<h1>This repository supports docker-compose orchestration for the registrar project</h1>

<h2>to use:</h2>
<ol>
	<li>download repository</li>
	<li>run on wsl with docker running: bash install.sh</li>
	<li>visit localhost:4200</li>
	<li>when done from directory call: docker-compose down</li>
	<li>on future runs to activate call: docker-compose up</li> 
</ol>
